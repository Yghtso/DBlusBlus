# 0005 — CRC32C primitive

Date: 2026-08-13

## Milestone/task

Phase 1: portable CRC32C checksum primitive for persistent page bytes.

## Scope

Implemented a deterministic, page-type-independent CRC32C function over
`std::span<const std::byte>`. The implementation is a portable bit-at-a-time baseline with no
heap allocation, external dependency, CPU intrinsics, runtime dispatch, page checksum policy, or
WAL/recovery behavior. No persistent format was changed.

No common-page checksum helper was added. Treating the persisted checksum field as zero remains
part of future whole-page checksum integration.

## Public API introduced

Declared in `common/crc32c.h`:

```cpp
[[nodiscard]] std::uint32_t Crc32c(std::span<const std::byte> bytes) noexcept;
```

The function accepts any byte span, performs no allocation, and returns the complete CRC32C value.

## Algorithm and polynomial convention

The implementation uses CRC-32C/Castagnoli with:

- width: 32 bits
- normal polynomial: `0x1EDC6F41`
- reflected polynomial used by the implementation: `0x82F63B78`
- initial remainder: `0xFFFFFFFF`
- reflected input/output convention
- final XOR value: `0xFFFFFFFF`
- canonical check value for `"123456789"`: `0xE3069283`

Bytes are processed individually with right shifts. This is CRC32C, not CRC-32/ISO-HDLC.

The tests cover empty input; single-byte and short text; the canonical `"123456789"` vector; 32

RFC 3720 section B.4.

## Assumptions

- A `std::byte` represents an 8-bit octet on the locked Linux x86-64 and ARM64 baseline targets.
- A correctness-first bit-at-a-time implementation is sufficient for this milestone.
- Whole-page code added later will provide zeroed checksum-field semantics before invoking this
  primitive.

## Known limitations and deferred work

- The baseline is intentionally not table-driven or hardware accelerated.
- SSE4.2, ARM CRC instructions, runtime CPU dispatch, and performance benchmarking are deferred.
- Whole-page checksum calculation/verification, including treating common-header bytes 16–19 as
  zero, is deferred.
- Checksum enable/disable policy and corruption handling are deferred.
